# NBA Scoring Efficiency Analysis

## Project Overview
This project performs exploratory data analysis (EDA) on NBA player performance. It is focused on the scoring efficiency and points contributed per 10 minutes of play. This was submitted as a final group project for **CIS 2100**

## Key Objectives
* Analyze player scoring metrics and efficiency across different game scenarios.
* Quantify scoring contribution per 10 minutes played (`Points / 10 Min`).
* Visualize trends and distribution using statistical visualizations.

## Repository Contents
* `CIS_2100_Final_Group_Project (1).ipynb`: Jupyter Notebook containing data loading, cleaning, analysis, and visualizations.
* `CIS 2100 Final Group Report (1).pdf`: Detailed written report summarizing methodology, insights, and conclusions.
* `CIS 2100 Final Project Group Presentation (1).pptx`: Slide deck summarizing key findings for presentation.

## Technologies Used
* **Python**
* **Pandas** – Data manipulation and aggregation
* **Matplotlib & Seaborn** – Data visualization
* **Jupyter Notebook** – Interactive analysis environment
